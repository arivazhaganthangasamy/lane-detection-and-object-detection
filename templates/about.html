How It Works
Detection Pipeline
Each frame passes through a carefully tuned computer-vision pipeline before object detection runs.
01
🎞
Frame Capture
Video decoded frame-by-frame via OpenCV. Supports MP4, AVI, MOV and live webcam streams.
02
🌫
Preprocessing
Grayscale conversion + Gaussian blur reduces noise before edge detection.
03
✏️
Edge Detection
Canny algorithm extracts sharp intensity gradients that correspond to lane markings.
04
📐
ROI Masking
A trapezoidal region-of-interest focuses processing on the drivable area ahead.
05
📏
Hough Lines
Probabilistic Hough transform detects line segments, averaged into solid left/right lanes.
06
🎯
YOLOv11
Custom-trained YOLOv11 model identifies vehicles, pedestrians, and road objects at speed.
07
🚨
Alert Logic
Object centroids are tested against lane boundaries. Violations trigger real-time alerts.
Technology
Built on Proven Tools
Vision

OpenCV

Industry-standard computer vision library handling frame capture, morphological operations, and drawing utilities.

Detection

YOLOv11

Ultralytics' latest YOLO architecture — faster and more accurate than previous versions, fine-tuned on road datasets.

Backend

Flask

Lightweight Python web framework serving the detection API, video streaming endpoint, and user authentication.

Algorithm

CNN Lane Engine

Canny edges + Hough transform + weighted slope averaging produces stable, flicker-resistant lane lines.

Alert System

Lane Crossing Detection

For every detected object, the system computes the object's centroid and checks which side of each lane line it falls on using a signed cross-product. If the centroid is outside the safe lane corridor, an alert fires immediately.
